# Contributing to MySQL Professional Notes

Thanks for your interest in improving this repository! Contributions of all kinds are welcome — fixing typos, expanding notes, adding diagrams, or contributing new real-world project examples.

## How to Contribute

1. **Fork** the repository and create your branch from `main`.
2. Make your changes inside the relevant numbered folder (keep the existing naming convention: `NN-topic-name.md`).
3. If adding a new topic, update the folder's structure and this repo's `README.md` table of contents.
4. Keep notes concise, practical, and example-driven — code blocks with runnable SQL are preferred over long prose.
5. Run a spell-check and preview your Markdown before submitting.
6. Open a Pull Request using the provided template, describing what changed and why.

## Style Guidelines

- Use sentence-case headings.
- Prefer fenced code blocks with the `sql` language tag for query examples.
- Keep one concept per file where possible.
- Link to official MySQL documentation for authoritative details when relevant.

## Reporting Issues

Please use the issue templates under `.github/ISSUE_TEMPLATE/` for bug reports (e.g., incorrect information) or feature requests (e.g., a missing topic).

## Code of Conduct

Be respectful and constructive. This is a learning resource meant to help the community — keep discussions focused and welcoming to newcomers.
