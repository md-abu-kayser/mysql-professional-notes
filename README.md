# MySQL Professional Notes

A comprehensive, structured collection of MySQL notes — from fundamentals to production-grade administration, performance tuning, replication, and real-world project patterns.

## What's Inside

- **00-prerequisites** — Relational database concepts, installation, SQL basics, CLI tools
- **01-getting-started** — MySQL fundamentals, connecting, CRUD
- **02-data-types** — Numeric, string, date/time, JSON, spatial types
- **03-sql-fundamentals** — SELECT, joins, subqueries, CTEs, set operations
- **04-functions-and-aggregation** — Aggregates, GROUP BY, string/date functions, window functions
- **05-indexing** — B-tree, hash, composite/covering indexes, EXPLAIN
- **06-transactions-and-locking** — ACID, isolation levels, locking, deadlocks, MVCC
- **07-stored-programs** — Procedures, functions, triggers, events
- **08-views-and-temporary-tables** — Views, updatable views, temp tables, materialized views
- **09-security-and-user-management** — Auth, GRANT/REVOKE, roles, SSL/TLS, SQL injection defense
- **10-backup-and-recovery** — Logical/physical backups, PITR, restore procedures
- **11-replication** — Binary logs, async/semi-sync replication, Group Replication
- **12-high-availability-and-scalability** — Read/write splitting, sharding, NDB Cluster
- **13-performance-tuning** — Buffer pool, slow query log, performance schema, profiling
- **14-partitioning-and-archiving** — Partition types, pruning, archiving
- **15-mysql-shell-and-devops** — MySQL Shell, Ansible, Docker, Kubernetes
- **16-cloud-and-managed-services** — RDS/Aurora, Cloud SQL, Azure Database, PlanetScale
- **17-migration-and-upgrades** — Cross-database migration, version upgrades
- **18-real-world-projects** — E-commerce schema, multi-tenant SaaS, logging systems, dashboards, clustering
- **19-code-snippets** — Reusable SQL, stored procedure templates, backup scripts
- **20-resources-cheatsheets** — Command-line cheatsheet, common errors, best practices, interview prep

## How to Use

Each topic lives in its own numbered folder so you can follow along in order, or jump straight to what you need — the folder numbers roughly track a learning progression from basics to advanced/production topics.
