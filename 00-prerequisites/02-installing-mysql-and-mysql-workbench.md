# Installing MySQL & MySQL Workbench

- **Linux**: `sudo apt install mysql-server` (Ubuntu), `sudo yum install mysql-server` (RHEL)
- **macOS**: `brew install mysql` or download from mysql.com
- **Windows**: MySQL Installer
- **Docker**: `docker run -d -p 3306:3306 -e MYSQL_ROOT_PASSWORD=root mysql:8`
- GUI: MySQL Workbench, DBeaver, DataGrip
