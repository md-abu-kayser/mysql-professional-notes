# Basic CRUD Operations

- CREATE: `INSERT INTO users (name, email) VALUES ('Alice', 'alice@example.com');`
- READ: `SELECT * FROM users;`
- UPDATE: `UPDATE users SET name = 'Bob' WHERE id = 1;`
- DELETE: `DELETE FROM users WHERE id = 2;`
